# UD1 - Ficheros (prácticas)

Ejercicios de Acceso a Datos sobre manejo de ficheros en Java.

| Paquete | Contenido |
|---|---|
| `Sesion1_File` | `File` y `Files`: info de ficheros, crear, borrar, `mkdir`/`mkdirs`, listar y recorrer carpetas |
| `Sesion2_Excepciones` | Borrado con `Files.delete()` y tratamiento de excepciones |
| `Sesion3_ficherosTexto` | `FileReader`/`FileWriter`, `BufferedReader`/`BufferedWriter`: contar vocales y palabras, diario, unir ficheros |
| `Sesion4_PrintWriterScanner_CSV` | Media de temperaturas con `Scanner`/`PrintWriter` y CSV de libros |
| `Sesion5_CapasArquitectura` | Modelo-Repositorio-Servicio con CSV: festival (bandas/músicos) y mundial de F1 (escuderías/pilotos) |
| `Sesion6_Binarios` | `DataOutputStream`/`DataInputStream` y copia de imagen con y sin buffer |
| `Sesion8_randomaccessfile` | `RandomAccessFile`: demostración e inventario con registros de tamaño fijo |
| `Sesion9_xml` | DOM: escribir/leer `museo.xml` y filmoteca de películas |

Los programas se ejecutan con la raíz del proyecto como directorio de trabajo.
